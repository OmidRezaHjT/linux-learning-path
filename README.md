# 🐧 Linux Learning Path

A structured collection of Linux commands, notes, and scripts documenting my journey toward LPIC-1 certification and beyond.

> 📚 Based on [linux1st.com](https://linux1st.com) — notes are written bilingually (English + Finglish) for faster review and recall.

## 📂 Structure

| File | Covers |
|------|--------|
| `notes/commands.txt` | Every command learned, with syntax, key switches, and dual-language explanations |
| `notes/filesystem.txt` | Filesystem concepts — permissions, inodes, superblocks, fstab, UUIDs |
| `notes/hardware.txt` | Hardware and boot-related topics |
| `notes/processes.txt` | Process management concepts |
| `notes/editors.txt` | Editor configs and shortcuts (vim, etc.) |

## 📝 Format

Each entry follows a consistent pattern for quick scanning:

```
## COMMAND

"command [options] [target]"
English: What it does, plus important switches.
Finglish: همون توضیح، به فینگلیش برای مرور سریع‌تر.
```
